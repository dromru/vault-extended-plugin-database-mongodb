# Vault database secrets engine - MongoDB plugin

Плагин является доработкой [официального плагина](https://github.com/hashicorp/vault/tree/main/plugins/database/mongodb) Vault.
Отдельного репозитория плагин не имеет, поэтому форк невозможен.

## Что изменено

1. Добавлена возможность прокидывать привилегии и создавать по ним роли. Таким образом можно указывать привилегии на коллекции.
2. Добавлена возможность указывать допустимые IP юзера.

## Ограничения

- Кастомные роли `<serviceName>_<hash>` создаются в admin-базе один раз на уникальную
  комбинацию `(база, коллекция, действия)` и используются совместно всеми пользователями.
  При удалении пользователя (revoke) роли НЕ удаляются — они остаются в MongoDB
  («сиротские» роли) и накапливаются по мере появления новых комбинаций привилегий.
  Очистка выполняется вручную: роли, не назначенные ни одному пользователю,
  можно найти через `rolesInfo` и удалить командой `dropRole`.
- Пользователь соединения (connection_url) должен иметь право создавать роли
  и читать `rolesInfo` в admin-базе (например, роль `root` или `clusterAdmin`).
